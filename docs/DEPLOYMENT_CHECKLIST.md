# 部署检查清单

在部署 ZbxTable 到生产环境之前，请确保完成以下检查项。

## 📋 部署前检查

### 环境准备

- [ ] 服务器满足最低配置要求（2GB+ 内存，10GB+ 磁盘）
- [ ] 已安装 Docker 和 Docker Compose（Docker 部署）
- [ ] 已安装 MySQL 8.0+ 或 PostgreSQL 12+（二进制部署）
- [ ] 防火墙已配置，开放必要端口（8085）
- [ ] 已配置域名和 DNS 解析（如果使用域名）

### 数据库准备

- [ ] 数据库已创建
- [ ] 数据库用户已创建并授权
- [ ] 数据库连接测试通过
- [ ] 数据库字符集为 utf8mb4
- [ ] 已配置数据库备份策略

### 配置文件

- [ ] 已复制 `config/app.conf.example` 为 `config/app.conf`
- [ ] 已修改数据库连接信息
- [ ] 已修改 API Token 为随机字符串
- [ ] 已配置日志路径和级别
- [ ] 已配置日志保留天数
- [ ] 已检查所有配置项

### Zabbix 连接

- [ ] Zabbix API 地址正确
- [ ] Zabbix 用户名和密码正确
- [ ] Zabbix 用户有足够权限
- [ ] Zabbix API 连接测试通过
- [ ] 网络连接正常

### 安全配置

- [ ] 已修改默认管理员密码
- [ ] 已修改数据库密码
- [ ] 已修改 API Token
- [ ] 已配置 HTTPS（推荐）
- [ ] 已限制管理端口访问
- [ ] 已配置防火墙规则
- [ ] 已禁用不必要的服务

### 日志配置

- [ ] 日志目录有写入权限
- [ ] 日志级别设置合理（生产环境建议 1 或 2）
- [ ] 日志保留天数设置合理
- [ ] 日志文件大小限制合理
- [ ] 已启用日志自动分割
- [ ] 已启用日志自动压缩

## 🚀 部署步骤

### Docker 部署

- [ ] 已克隆项目代码
- [ ] 已配置 `config/app.conf`
- [ ] 已配置 `docker-compose.yml`（如需修改）
- [ ] 已执行 `docker-compose up -d`
- [ ] 容器启动成功
- [ ] 健康检查通过
- [ ] 可以访问 Web 界面

### 二进制部署

- [ ] 已下载或编译二进制文件
- [ ] 已配置 `config/app.conf`
- [ ] 已创建必要的目录（log, download, template）
- [ ] 已配置 systemd 服务（推荐）
- [ ] 服务启动成功
- [ ] 可以访问 Web 界面
