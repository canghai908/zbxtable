# ZbxTable

[![Build Status](https://drone.cactifans.org/api/badges/canghai908/zbxtable/status.svg?ref=refs/heads/2.1)](https://drone.cactifans.org/canghai908/zbxtable)

ZbxTable is a Zabbix report system developed using Go language.

## Features

- 🎨 Custom drawing topology
- 📊 Device classification display and export
- 📈 Export Zabbix alert messages to xlsx within a specific time period
- 🔍 Analyze the alarm messages in a specific time period, alarm Top 10, etc.
- 📅 Scheduled report generation and automatic delivery
- 📧 Multi-channel notifications (Email, WeChat Work)
- 🌐 Multi-tenant support for multiple Zabbix instances
- 🔐 Role-based access control

## Architecture

![1](/zbxtable.png)

## Component

**ZbxTable**: Backend written using [Gin framework](https://github.com/gin-gonic/gin) and Go language.

**ZbxTable-Web**: Front end written using [Vue](https://github.com/vuejs/vue).

**MS-Agent**: Installed on Zabbix Server, used to receive alarms generated by Zabbix Server and send to ZbxTable.

## Quick Start

### Docker Deployment (Recommended)

```bash
# Clone the repository
git clone https://github.com/canghai908/zbxtable.git
cd zbxtable/zbxtable

# Copy configuration file
cp config/app.conf.example config/app.conf

# Edit configuration (modify database settings)
vim config/app.conf

# Start services
docker-compose up -d

# View logs
docker-compose logs -f zbxtable
```

Visit `http://localhost:8085` to access the application.

For detailed Docker deployment instructions, see [Docker Deployment Guide](./deployments/docker/README.md).

### Binary Deployment

```bash
# Download the latest release
wget https://github.com/canghai908/zbxtable/releases/latest/download/zbxtable-linux-amd64.tar.gz
tar -xzf zbxtable-linux-amd64.tar.gz
cd zbxtable

# Configure database
cp config/app.conf.example config/app.conf
vim config/app.conf

# Start the service
./zbxtable web
```

## Configuration

### Log Configuration

ZbxTable uses Logrus + Lumberjack for log management with the following features:

- **Date-based naming**: Log files are automatically named by date (yyyy-MM-dd.log)
- **Automatic rotation**: Logs are automatically rotated when reaching the configured size
- **Automatic compression**: Old log files are automatically compressed to .gz format
- **Automatic cleanup**: Logs older than the configured retention period are automatically deleted
- **Default path**: If `log_path` is empty, defaults to `./log/yyyy-MM-dd.log`

Example configuration in `config/app.conf`:

```ini
log_level = 6      # Log level: 0-6 (0=Panic, 1=Info, 2=Error, 3=Warn, 4=Info, 5=Debug, 6=Trace)
log_path  =        # Log path, leave empty for default ./log/yyyy-MM-dd.log
maxsize   = 100    # Maximum size per log file (MB)
maxdays   = 10     # Log retention days
daily     = true   # Enable daily log rotation
```

## Compile from Source

Requirements: Go >= 1.23

```bash
# Clone the repository
mkdir -p $GOPATH/src/github.com/canghai908
cd $GOPATH/src/github.com/canghai908
git clone https://github.com/canghai908/zbxtable.git
cd zbxtable/zbxtable

# Download frontend assets
wget -q -c https://dl.cactifans.com/stable/zbxtable/web-latest.tar.gz && tar xf web-latest.tar.gz

# Build
go build -o zbxtable main.go

# Or use the control script
./control build
./control pack
```

## Docker Build

# Build from source
